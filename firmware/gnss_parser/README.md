# GNSS parser

Docelowo ten folder będzie zawierał własny parser komunikatów NMEA dla odbiornika GNSS.

Plik `gnss_parser.ino` jest celowo pusty. Kod będziemy pisać wspólnie krok po kroku, zaczynając od odbioru bajtów, a następnie dodając parsowanie i walidację danych. Nie wgrywaj pustego pliku jako programu docelowego.

Aktualne połączenie testowe opisane przez użytkownika: GPS TX → Arduino D4; GND → GND; VCC według dotychczas używanej konfiguracji modułu. GPS RX i PPS pozostają niepodłączone. Zasilanie modułu oraz poziomy logiczne należy traktować zgodnie z właściwościami konkretnej płytki.

# Przygotowanie danych mapowych

To miejsce na skrypty i instrukcje przygotowania lokalnych danych mapowych.

Nie wybieramy jeszcze formatu ani obszaru mapy. Najpierw trzeba ustalić docelowy kontroler, ekran, wymagania pamięciowe i sposób renderowania. Dane OpenStreetMap podlegają warunkom licencji ODbL i wymagają odpowiedniej atrybucji; sposób prezentacji atrybucji zostanie uwzględniony w projekcie.

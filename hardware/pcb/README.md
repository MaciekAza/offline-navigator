# PCB

Przechowuj tu pliki projektu KiCad (`.kicad_pcb` i powiązane źródła), a po zatwierdzeniu rewizji również pliki produkcyjne, BOM oraz rysunki montażowe.

Dla każdej rewizji zapisz numer wersji, listę zmian, kontrolę DRC i status prototypu. Nie dodawaj plików produkcyjnych przed zakończeniem kontroli projektu.

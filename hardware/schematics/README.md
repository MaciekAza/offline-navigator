# Schematy

Przechowuj tu źródła KiCad (`.kicad_sch`) oraz eksporty PDF do przeglądania.

Każdy schemat powinien zawierać oznaczenia komponentów, wartości, złącza, sieci zasilania i uwagi dotyczące zakresów napięć. Nie umieszczaj tutaj schematów, które przedstawiają połączenia niezweryfikowanych modułów jako gotowe do montażu.

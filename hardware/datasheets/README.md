# Dokumentacja komponentów

W pierwszej kolejności zapisuj producenta, dokładne oznaczenie i stabilny link do oficjalnej dokumentacji w pliku decyzji lub tabeli komponentów. Kopie plików PDF dodawaj wtedy, gdy licencja i warunki producenta na to pozwalają.

Przydatne źródła do rozpoczęcia weryfikacji:

- [Arduino UNO R3 — dokumentacja i datasheet](https://docs.arduino.cc/hardware/uno-rev3/)
- [u-blox NEO-7 series — strona producenta](https://www.u-blox.com/en/product/neo-7-series)
- [u-blox NEO-7 — datasheet](https://content.u-blox.com/sites/default/files/products/documents/NEO-7_DataSheet_%28UBX-13003830%29.pdf)

Sama zgodność nazwy w aukcji lub na opisie handlowym nie potwierdza schematu breakout boardu.
